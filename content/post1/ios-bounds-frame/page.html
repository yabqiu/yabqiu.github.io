frame和bounds是UIView中的两个属性(property)。

frame指的是：该view在父view坐标系统中的位置和大小。（参照点是父亲的坐标系统）

bounds指的是：该view在本身坐标系统中 的位置和大小。（参照点是本身坐标系统）
{{< highlight objc >}} -(CGRect)frame{ 　　return CGRectMake(self.frame.origin.x,self.frame.origin.y,self.frame.size.width,self.frame.size.height); } {{}}
{{< highlight objc >}} -(CGRect)bounds{ 　　return CGRectMake(0,0,self.frame.size.width,self.frame.size.height); } {{}}
