{{< highlight xml >}} resources/icustomer/Contact.hbm.xml resources/icustomer/Customer.hbm.xml ................... {{}}
每当需要加入一个新的 VO 时，我需要过来修改配置文件，来引入对新的 VO 的支持。

现在我使用的时候，是这么配的：
{{< highlight xml >}} classpath:resources/**/*.hbm.xml ..................... {{}}
做项目开发的时候，就再也没有改过配置。
{{< highlight xml >}} classpath*:domain/mappings/ {{}}
还可以使用上面这种配置

注明一下，我所用的 Spring 版本是 2.0 的。
